# AdSense審査改善プラン（URLclickable / ツール型サイト向け）

## 1. 先に共有：この環境での調査制約
- 本来は「YouTubeの最新解説動画」と「Google公式ヘルプ」をネット検索して根拠を照合する予定でした。
- ただし、この実行環境から外部WebへのHTTPS接続が `403 Forbidden` でブロックされ、動画・記事の直接確認ができませんでした。
- そのため本ドキュメントは、AdSense審査で一般的に重視される要件と、審査落ちしやすいサイトの典型問題をベースにした改善提案です。

---

## 2. AdSense審査で落ちやすいポイント（ツール型サイト観点）

### P0（最優先）
1. **ツール以外の説明コンテンツが薄い**
   - 「入力欄とボタンだけ」で価値説明が不足している状態は不利。
2. **運営者情報・問い合わせ・プライバシーポリシーが不足**
   - 「誰が運営しているか」が不明なサイトは信頼性で落ちやすい。
3. **サイト構造が未整備（クローラビリティ不足）**
   - ナビゲーション不明瞭、死活リンク、noindex設定ミス、公開ページが少ない。
4. **ポリシー違反リスク（著作権・不正利用・誘導設計）**
   - ツールの悪用を助長する説明や、誤認を生む表現がある。

### P1（重要）
5. **モバイル表示や表示速度が弱い**
   - CLS/LCPが悪い、重い画像、不要なJS。
6. **利用方法・制限事項・免責が不明確**
   - 何ができて何ができないかが不明で、品質評価が下がる。
7. **広告配置とUXのバランスが悪い**
   - 本体機能より広告が目立つ配置は不利になりやすい。

## 3. URLclickable向け改善方針（記事なし前提）

### 方針A：信頼性ページを最短で揃える
- `/about`（運営者・目的・更新方針）
- `/contact`（問い合わせフォーム or メール）
- `/privacy`（広告配信・Cookie・アクセス解析の説明）
- `/terms`（利用規約）

### 方針B：ツール説明ページを中核にする
- ブログ記事ではなく、以下の固定説明を整備：
  - `/how-it-works`（仕組み）
  - `/use-cases`（利用シーン）
  - `/faq`（よくある質問）
  - `/limitations`（制限事項・免責）
- 各ページで以下を統一：
  - 何を解決するツールか（冒頭）
  - 具体的な使い方（手順）
  - できること / できないこと
  - 安全な使い方・禁止用途
  - 最終更新日

### 方針C：技術的な審査阻害要因を除去
- `noindex`/`nofollow`の誤設定チェック
- 404/リダイレクトループ解消
- サイトマップ・内部リンク・パンくず導入
- モバイルUI最適化（可読性、タップ領域）

### 方針D：再申請前の品質ゲートを作る
- 必須固定ページの有無、導線、更新日、説明の明確さをチェックする運用ルールを用意。

## 4. 再申請までの実行計画（2週間）

### Week 1
- Day 1-2: 信頼性ページ（about/contact/privacy/terms）を公開
- Day 3-4: ツール説明ページ（how-it-works/use-cases/faq/limitations）を公開
- Day 5-7: 内部リンク設計・ナビゲーション改善

### Week 2
- Day 8-10: UI文言改善（使い方、注意事項、エラーメッセージの明確化）
- Day 11: 表示速度・モバイル表示の改善
- Day 12: インデックス状態確認（Search Console想定）
- Day 13: ポリシー違反リスク監査
- Day 14: 最終チェック後にAdSense再申請

---

## 5. 実装提案（今回の次アクション）

1. まずテンプレートページを実装
   - `about` / `contact` / `privacy` / `terms` の4ページを先に固定ページとして追加。
2. ツール説明ページを実装
   - `how-it-works` / `use-cases` / `faq` / `limitations` を追加。
3. サイト共通フッターを追加
   - 各必須ページへのリンクを全ページから1クリックで到達可能に。
4. 審査前チェックリストを運用
   - 本ドキュメントと `docs/adsense-precheck-checklist-ja.md` を使って事前点検。
